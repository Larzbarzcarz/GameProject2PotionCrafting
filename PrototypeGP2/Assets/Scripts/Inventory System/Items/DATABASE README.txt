CREATE A SCRIPTABLE OBJECT (S.O) BY GOING:
RIGHT KLICK -> CREATE -> INVENTORY SYSTEM -> ITEMS -> CHOOSE WHICH S.O YOU WANT TO CREATE

DRAG AND DROP THE S.O IN TO THE INSPECTOR FOR DATABASE
THE ITEMS THAT ARE STORED IN THE DATABASE GETS AN ID THAT WE CAN SEE IN THE PLAYER INVENTORY->INSPECTOR
THIS WILL SAVE THE ITEMS FOR THE PLAYER THROUGH THE SESSIONS
